## 3. Goal & Non-Goal

**Goal:** Tombol "Generate Foto" menghasilkan **foto kegiatan riil** (bukan canvas) via
`puter.ai.txt2img`, dengan wajah personel terpilih sebagai input image-to-image, foto masuk
ke Panel Preview lewat alur state Sprint 019 revisi yang sudah terverifikasi.

**Non-Goal (di luar scope):**
- Text AI (notulen `MaminSeksi6Notulen.jsx`, tanya BKU `AskAIPanel.jsx`) — infra sudah jalan.
- Menu BYOK / pengaturan API key.
- Jalur fal.ai Flux Pro (tetap komentar, bukan scope).
- Perubahan alur state foto / dokumen A4 / print twin Sprint 019 revisi.
- Penilaian estetika hasil foto (acceptance = foto riil muncul & terintegrasi, bukan rasa).

## 4. Risiko Utama

| Risiko | Mitigasi |
|---|---|
| Popup sign-in Puter saat pemakaian pertama | Hint jujur di UI kartu AI + pesan error jelas |
| Param image-to-image / return type belum terverifikasi di kode | Verifikasi wajib saat implementasi (V-1…V-4 di BLUEPRINT) |
| Puter error / offline | Fallback canvas placeholder + label jujur "placeholder" |
| Kualitas wajah dari foto kecil | Di luar acceptance; user menilai sendiri, regenerate tersedia |
